# Intel Sustainability Data Analysis
## Overview
This project analyzes sustainability data from Intel to identify trends in their environmental performance and support data recommendations. The goal was to explore key metrics such as emissions, energy usage, and operational efficiency using data analysis and visualization.

## Tools & Technologies
- Python (pandas, matplotlib)
- Excel (PivotTables, data cleaning)

## Data
The dataset includes sustainability metrics such as energy consumption, emissions, and operational data. The data was provided as CSV files and required preprocessing before analysis.

## Methodology
- Cleaned and preprocessed raw data for analysis
- Performed exploratory data analysis to identify trends
- Built visualizations to highlight key patterns
- Analyzed changes across time and categories

## Findings
- Older repurposed devices save more energy per year as device age increases.
- Despite their higher energy-saving potential, older devices are repurposed less frequently than newer ones.
- Each repurposed device saves an average of 28.4 kWh annually, which is equivalent to removing 60 cars.
- Increasing device repurposing creates an opportunity to cut energy use and reduce environmental impact by alot.
